# ESP32-C3 RID 固件 — OLED 屏幕 UI 规格（重构后）

屏幕 72×40，5×7 字体：每行 12 字符、共 4 行（反显标题栏 + 3 行数据）。
底部行每 2.2 秒在「模式信息 ↔ 时间」之间轮播。

> **与任务书的重要冲突（已按底层实现为准）**
> 任务书 §8.2 要求"离开中继页去 RID 页但中继不停"。本固件 `RID / SHOT / RELAY`
> 是**三个互斥固件模式**：RID 嗅探、BLE 键盘、Wi-Fi 中继分别占用 ESP32-C3 单射频，
> 切换模式必须重启（现有 `crid_mode_request` 机制）。因此：
> - **同一时刻只能处于一个模式**，进另一个模式 = 主页双击 → 确认 → 重启。
> - "离开中继展示页 → 主页"中继照常跑 ✓（满足）；"去 RID 页但中继不停"做不到 ✗（硬件限制）。

## 一、导航状态机

```
UI_HOME ──双击进入所选功能──► UI_FUNC（当前模式根页）
   ▲                              ├─ RID  → 设备列表（双击进详情，长按回 HOME）
   │                              ├─ SHOT → 拍照页（见 §三）
   │                              └─ RELAY→ 中继页（单击换页，长按回 HOME）
   │                              UI_DETAIL（RID 详情，长按/双击回列表）
   │                              UI_SET_GAP（间隔设置，双击确认，长按取消）
   └── 任意子页/确认页空闲 30s 自动退回；三击也可一键回 HOME（逃生键）
```

## 二、统一按键规则

| 操作 | 含义 | 用途 |
|---|---|---|
| 单击 | 一次短按 | 选择 / 切换 / 执行当前页动作 |
| 双击 | 两次短按 | 进入页面 / 确认 / 打开设置 |
| 长按 | ~0.7s | **返回上一级**（HOME 长按无操作） |
| 超长按 | ~2.5s | **仅切屏幕亮灭**（不与长按互斥） |

- 双击窗口内暂缓派发单击，避免双击误触单击（由 `crid_button` 统一识别 SINGLE/DOUBLE/TRIPLE/LONG/VERYLONG）。
- 熄屏后首次任意按键**只唤醒并消费该次操作**，不会误触拍照 / 翻页 / 返回（任务书 §4.3）。
- 熄屏期间 RID 扫描、定时拍摄、中继业务照常运行（屏幕刷新与业务逻辑解耦）。

## 三、各页示例数据（虚构，仅演示排版）

**HOME（启动默认页）**
```
▓HOME      ▓
 ▶RID
  SHOT
  RELAY
```
`▶` 为反显选中；`*` 标记当前固件模式（如 `*RELAY`）。

**RID 设备列表**（单击移动选择 / 双击进详情 / 长按回 HOME）
```
▓RID LIST  ▓
▶#1 AB12 -72
 #2 C3F9 -80
 #3 1A00 -65
N=3
```
无目标时显示 `NO UAV` + 底部 `SCAN`（或 `SIM ON`）。

**RID 设备详情**（标题=序号+尾号，右上方 RSSI；三行 SPD/ALT/HDG；单击下一个 / 长按回列表）
```
▓U1 M30T8F3A2 ▓
SPD 12.4m/s
ALT 86m
HDG 268
```
RSSI 用真实 dBm；无数据时显示 `RSSI --`，绝不伪造距离。

**拍照页（SHOT / 键盘模式）**
- 手动档（停止）：`GAP MANUAL` / `1X = SHOT` 或 `NO LINK` / `SHOTS 0`
- 定时运行：`SHOT` 标题 + 左侧大号倒计时 + `GAP 10s` + `SHOT 34` + `LINKED`
- 定时暂停：`PAUSED` 代替倒计时（其余不变）
- 手势：手动单击拍照 / 双击开间隔设置 / 长按回 HOME；定时单击暂停恢复 / 双击开设置 / 长按停止并回 HOME

**间隔设置页**（单击循环档位 / 双击确认 / 长按取消）
```
▓INTERVAL  ▓
GAP 10s
1X = NEXT
2X = SAVE
```
档位严格为 `MANUAL / 3 / 5 / 10 / 15 / 20 / 30 / 60`（秒）。

**中继页**（3 页自动轮播，每 ~2.2s 翻一页；单击手动换页；长按回 HOME；双击无操作）
```
▓RELAY    ▓        ▓DATA     ▓        ▓SPEED    ▓
STA HIDDEN          UP 12.4M          128.4K/s
DEV 2              DN 86.3M          1.2M/s
NAT ON             ALL 98.7M         RELAY ON
```
- Page0 连接信息：SSID（`HIDDEN` 替代中文/乱码）、客户端数量、NAT 状态
- Page1 累计流量：上行 / 下行 / 总计
- Page2 实时速率：上行 / 下行
- 数据全部来自 `crid_relay_sta_info` / `crid_relay_client_list` / `crid_relay_traffic`，无数据时显示 `--`。

**配对码页**（蓝牙配对中压过一切，6 位大号数字铺满 72px）
```
▓PAIR     ▓
 ███ ██  ███
 KEY IN PHONE
```

## 四、数据与业务解耦

- RID：`crid_tracker_*` 带互斥锁，`collect_uav()` 只抽取 5 字段，不改动跟踪表。
- 拍照：连接/运行/暂停/倒计时/张数来自 `crid_shutter_get_status()`；定时节拍在
  `shutter_task` 内（`s_next_at`，与屏幕刷新、熄屏、翻页完全解耦）。
- 中继：`crid_relay_*` 为结构化接口（无 JSON、低栈安全），屏幕只读。
- 屏幕状态（`s_on`）、UI 状态（`s_ui`）、业务状态（模式/拍照/中继）三者严格分离：
  退出页面 / 熄屏**不会**停止任何后台业务。

## 五、无屏兼容

`crid_oled_init()` 探测不到 SSD1306 即 `crid_screen_init()` 返回 OK、不建按键/刷新任务；
其余业务照常。日志：`no OLED ... screen & button disabled`。
