💡 灯语说明

常亮：正常运行且近期有数据；慢闪：正常运行无数据；快闪：正在接收或蓝牙活动；呼吸：中继/联网中；熄灭：模式切换重启中。上方指示灯与板载蓝灯同步，心跳停止增长即表示程序可能跑飞。

🔲 校准与自检图案

图案会锁定屏幕，不会被正常界面刷掉；按一下 BOOT 键或点「清除」即可退出。

校准图怎么看：偏移正确时，四个角的 3×3 实心块应完整且紧贴面板四角，四条边框都在。
• 缺左边框 / 左角块被切 → X 偏大，调小
• 缺右边框 / 右侧有黑边 → X 偏小，调大
• 缺上边框 / 上角块被切 → Y 偏大，调小
• 缺下边框 / 下方有黑边 → Y 偏小，调大
